# Cognitive maps and their verbal expression in psychosis

Companion repository for the ECNP 2026 poster **PS03-3229**, *Psychosis-related
disorganisation impairs the construction and verbal expression of relational
cognitive maps from visual experience*.

Xiaoyan Wu, Peizheng Wu, Finn Rabe, Wolfgang Omlor, Victoria Edkins, Yves Pauli,
Stephanie Theves, Wolfram Hinzen, Iris E. Sommer, Philipp Homan

Department of Adult Psychiatry and Psychotherapy, University of Zurich · Homan Lab

---

## The two papers

### 1. Cognitive maps — Disorganization impairs cognitive maps built from visual inputs

Cognitive disorganization selectively reduces spatial sensitivity and spatial
generalization when a relational map has to be built from visual input, but not
when the same structure is provided through language.

**Read it:** https://www.biorxiv.org/content/10.64898/2025.12.22.695951v3

### 2. Verbal expression — Teaching others externalizes spatial structure, selectively after visual learning

Explaining what was learned to another person brings two-dimensional structure
into natural speech, and higher disorganization shows up as answers that stray
from the question asked.

**Read it:** https://www.biorxiv.org/content/10.64898/2026.08.04.742691v1
